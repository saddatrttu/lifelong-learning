# Claude Code 使用指南

> Claude Code 是 Anthropic 出品的**终端原生 AI 编程代理**（Agentic Coding Tool）。它能理解整个代码库、自主编辑多个文件、运行终端命令、管理 Git 工作流，并通过 MCP 接入外部工具——全部通过自然语言完成。
>
> 本文是一套完整的参考手册，采用 **MOC + 多笔记** 结构，每个主题独立成篇，相互用 Obsidian 双向链接串联。

## 关键平台对比

Claude Code 与常见 AI 编码工具定位差异：

| 特性 | Claude Code | 传统 IDE 插件 |
|------|------------|--------------|
| 运行环境 | 终端原生 / 6 大平台 | IDE 内嵌 |
| 上下文 | 读取整个代码库 | 当前文件 + 有限上下文 |
| 编辑 | 多文件自主编辑 | 单文件建议 |
| 命令 | 可执行终端命令 | 无终端访问 |
| Git | 完整 Git 工作流自动化 | 有限或无 |
| 可扩展性 | MCP、Hooks、Skills、自定义命令 | 插件市场 |
