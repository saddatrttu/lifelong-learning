# Obsidian 知识库指南

## Overview

**核心原则：MOC 导航 + 多笔记同构。** 每套指南一个 MOC 主页作为导航入口，下挂若干编号笔记。文件名必须唯一且稳定，因为 Obsidian 的 `[[wiki-link]]` 按**文件名（不含路径）**解析——改名会断链，重名会串链。

## When to Use

- 在 Obsidian 知识库中新建一套指南（如「Claude Code」「Git」「自动化测试」）
- 创建 MOC 主页或编号笔记
- 处理 wiki-link、重命名文件、解决重名冲突
- 按目录逻辑顺序排列文件（Obsidian 无手动排序，需数字前缀）

## 组织规范

### 文件夹结构

每套指南一个独立文件夹，命名清晰（可含空格，如 `claude  code`）：

```
知识库根/
├── 指南A/
│   ├── 0-指南A MOC.md          # MOC 置顶
│   ├── 1-第一章.md
│   ├── 2-第二章.md
│   └── ...
├── 指南B/
└── 独立文件.md                  # 不属于任何指南的独立笔记留根目录
```

### 数字前缀排序

Obsidian 文件浏览器按文件名（Unicode 码点）排序，**无法手动固定顺序**。要让文件夹内文件按逻辑顺序显示，统一加数字前缀：

| 前缀 | 位置 | 用途 |
|------|------|------|
| `0-` | 每个文件夹 | MOC 主页 |
| `1-` `2-` `3-`... | 每个文件夹 | 编号笔记，按阅读顺序 |

- 排序顺序 = 逻辑顺序：`0-MOC` 最前，编号笔记依次排开
- 前缀后跟原有文件名，如 `1-CC-安装与入门.md`、`2-Git-核心命令与提交.md`

### 避免重名冲突

Obsidian 的 `[[链接]]` 按文件名解析，**不同文件夹下同名文件会冲突**。三套指南若都有 `1-安装与入门.md`，链接会串到任意一个。

**前缀命名方案**（每套指南一个唯一前缀）：
- Claude Code → `CC-`，如 `CC-安装与入门`
- Git → `Git-`，如 `Git-安装与入门`
- 自动化测试 → `Test-`，如 `Test-pytest入门`
- MOC 保留原名（`Claude Code 使用指南`），不加重名风险，且便于跨指南引用

组合使用：`数字前缀` + `指南前缀` + `章节名`，如 `1-CC-安装与入门.md`。

### 跨指南引用

- MOC 保留原名，跨指南引用 MOC 时链接名唯一
- 引用他指南的笔记时用对方的前缀名，如 Git 指南中引用 `[[2-CC-核心命令与交互]]`
- 非 MOC 的独立文件（如 `superpowers-使用说明`）可留根目录，不影响链接

## 写作规范

### MOC + 多笔记结构

每套指南包含：
1. **MOC 主页**：导航入口 + 心智模型 + 阅读路径（新手/进阶/专题）+ 关联指南
2. **编号笔记**：每章一个文件，聚焦单一主题，末尾带"延伸阅读"指向相关章节

### 指南结构模板

```markdown
# 指南名称

> 一句话定位（本文采用 **MOC + 多笔记** 结构，与仓库内其他指南同一套整理思路）

## 快速导航
- **新手**：按顺序 [[1-第一章]] → [[2-第二章]] → ...
- **进阶用户**：[[3-第三章]] → ...

## 章节索引
| 编号 | 章节 | 简介 |
|------|------|------|
| 0 | [[指南MOC\|本页 MOC]] | 导航入口 |
| 1 | [[1-第一章]] | 简介 |
| ...

## 关联指南
- [[其他指南MOC]] — 关联说明
```

### 交叉引用写法

- 章节内引用：`（见 [[2-第二章]]）`
- 带显示名的引用：`[[2-第二章\|显示名]]`
- 全角竖线 `\|` 是转义，防止被当作表格分隔符

### 链接维护

- 重命名文件必须同步更新所有指向它的 `[[链接]]`
- 批量改名时：先建映射表 → 逐个 `.Replace` → 最后统一验证
- 验证方式：收集所有 `[[xxx]]` 目标名，与仓库内文件名集合比对，无匹配即断链

## 创建流程

1. **先询问用户是否新建文件夹及文件夹名称**，不要擅自决定目录
2. 确定指南前缀（若可能与他指南重名）
3. 创建 MOC 主页（`0-指南名.md`）
4. 按章节创建编号笔记（`1-`、`2-`...）
5. 维护好 MOC 内的章节索引表与跨指南引用
6. 验证：所有 `[[链接]]` 都能解析到实际文件

## Common Mistakes

| 错误 | 后果 | 正确做法 |
|------|------|----------|
| 多套指南同名编号笔记 | wiki-link 串链 | 每套指南加唯一前缀 |
| 不加数字前缀 | 显示顺序≠逻辑顺序 | 用 `0-`、`1-`... 前缀 |
| 改名不断链 | 链接显示但点不开 | 改名后更新所有引用并验证 |
| 链接写带路径形式 | 移动文件夹后失效 | 只用文件名 |
| MOC 不置顶 | 导航入口淹没在列表中 | MOC 加 `0-` 前缀 |
| 中文编码问题 | 乱码 | 保存为 UTF-8 无 BOM |
