## Linux 是什么

Linux 只是一个**内核（Kernel）**，负责管理硬件与进程。用户实际接触的是"内核 + 外围软件"打包成的**发行版（Distribution）**：

| 发行版 | 包管理器 | 适用场景 |
|--------|----------|----------|
| Ubuntu / Debian | `apt` | 开发机、桌面、服务器（最流行） |
| CentOS / RHEL | `yum`/`dnf` | 企业服务器、运维 |
| Alpine | `apk` | 容器镜像（极小体积） |
| Arch | `pacman` | 滚动更新、极客玩家 |

> 本套指南的命令大部分在各发行版通用；安装软件时注意用对应包管理器。

## Shell 与终端

**终端（Terminal）** 是窗口程序，**Shell** 是解释命令的程序。默认 Shell 通常是 Bash（`echo $SHELL` 可查看）。

```bash
# 查看当前 Shell
echo $SHELL

# 切换 Shell
bash        # 进入 bash
zsh         # 进入 zsh（macOS 默认）

# 退出当前 Shell
exit
```

命令提示符 `huan@host:~$` 的含义：`用户名@主机名:当前目录$`（`#` 表示 root 用户）。

## 路径与目录结构

### 路径类型

| 写法 | 含义 | 示例 |
|------|------|------|
| `/` | 根目录 | `/` |
| `~` | 当前用户家目录 | `~` = `/home/huan` |
| `.` | 当前目录 | `./a.txt` |
| `..` | 上级目录 | `cd ..` |
| `-` | 上一个访问过的目录 | `cd -` |

### 目录结构（FHS 标准）

| 目录 | 作用 |
|------|------|
| `/bin` `/usr/bin` | 系统命令 |
| `/etc` | 配置文件 |
| `/home` | 普通用户家目录 |
| `/root` | root 用户家目录 |
| `/var/log` | 日志 |
| `/tmp` | 临时文件 |
| `/proc` `/sys` | 内核/进程虚拟文件系统 |

### 关键命令

```bash
pwd          # 打印当前绝对路径
cd /etc      # 切换目录
cd ~         # 回到家目录
ls           # 列出当前目录
ls -la       # 含隐藏文件(-a)的长格式(-l)
which ls     # 命令所在位置
```

## 获取帮助

忘记命令用法是常态，三条途径由浅入深：

```bash
# 1. 快速帮助（最常用，简要选项列表）
ls --help

# 2. 手册页（详细，含参数说明与示例）
man ls        # 退出按 q
man 5 passwd  # 查看配置文件的格式（章节 5）

# 3. 命令自带说明
info ls       # 更详细的文档（GNU）
```

> `man` 的章节号：1 用户命令、5 配置文件格式、8 系统管理命令。

## 通配符

Shell 会在执行命令前自动展开通配符，用于批量匹配文件：

| 通配符 | 含义 | 示例 |
|--------|------|------|
| `*` | 任意长度任意字符 | `*.log` 所有日志 |
| `?` | 单个任意字符 | `file?.txt` → file1.txt、fileA.txt |
| `[abc]` | 字符集内一个字符 | `file[1-3].txt` |
| `[!abc]` | 非字符集内一个字符 | `[!0-9]*` |

```bash
ls *.txt          # 列出所有 .txt
rm -f file[0-9]*  # 删除 file 开头的数字文件
```

> ⚠️ 通配符是 **Shell 展开**，与命令本身无关。引号包裹可禁止展开：`grep "a*b" file` 匹配字面 `a*b`。

## 命令格式与补全

```bash
# 通用格式：命令 [-选项] [参数]
ls -l /home
ls -lh /home          # 多个短选项可合并
ls --human-readable   # 长选项用 --
```

### Tab 补全

- 按一次 `Tab`：补全命令/文件名
- 按两次 `Tab`：列出所有可能
- 方向键 `↑↓`：翻历史命令
- `Ctrl+R`：搜索历史命令

### 历史命令

```bash
history           # 列出历史
!123              # 执行第 123 条
!!                # 执行上一条
sudo !!           # 用 sudo 执行上一条（经典）
```

## 常见问题

**Q：`sudo: command not found`？**
A：当前用户无 sudo 权限，或系统精简。切到 root：`su -`，或提示管理员把用户加入 sudo 组（见 [[4-Linux-权限与用户管理]]）。

**Q：提示 `Permission denied`？**
A：文件权限不足，用 `ls -l` 查看属主权限，`chmod`/`sudo` 解决（见 [[4-Linux-权限与用户管理]]）。

**Q：`~` 打不出来？**
A：`~` 在中文输入法下可能被吞，切换到英文输入法。

**Q：文件名包含空格怎么处理？**
A：加引号或转义：`cat "my file.txt"` 或 `cat my\ file.txt`。
