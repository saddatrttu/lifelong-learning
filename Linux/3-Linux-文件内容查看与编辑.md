## 查看内容

```bash
cat a.txt                # 直接输出全部内容（适合小文件）
cat -n a.txt             # 带行号
less a.txt               # 分页浏览（大文件推荐）
```

`less` 操作速记：

| 按键 | 作用 |
|------|------|
| 空格 / `f` | 下一页 |
| `b` | 上一页 |
| `/关键词` | 向下搜索（`n` 下一个） |
| `?关键词` | 向上搜索 |
| `g` / `G` | 首行 / 末行 |
| `q` | 退出 |

> 大文件**永远用 `less` 而非 `cat`**，避免刷屏卡死。

## 头部与尾部

```bash
head -n 10 a.txt         # 前 10 行（默认 10）
tail -n 20 a.txt         # 后 20 行
tail -f app.log          # 实时跟踪日志追加（日志调试神器）
tail -F app.log          # -f 增强版，文件被轮转后仍能跟随
```

> `tail -f` 是排查线上问题的第一工具：`tail -f /var/log/nginx/error.log`。

## 统计与拼接

```bash
wc -l a.txt              # 行数
wc -w a.txt              # 单词数
wc -c a.txt              # 字节数
wc -l a.txt b.txt        # 多文件分别统计

cat a.txt b.txt > c.txt  # 拼接两个文件（配合重定向）
```

## 重定向

把命令的输出从屏幕转到文件或其他地方：

| 符号 | 作用 | 示例 |
|------|------|------|
| `>` | 覆盖写入 | `echo hi > a.txt` |
| `>>` | 追加写入 | `echo hi >> a.txt` |
| `2>` | 重定向错误输出 | `ls /nope 2> err.txt` |
| `2>&1` | 错误并入标准输出 | `cmd > out.txt 2>&1` |
| `<` | 从文件输入 | `sort < in.txt` |
| `/dev/null` | 丢弃输出 | `cmd > /dev/null 2>&1` |

```bash
# 常见组合：把脚本日志同时写到文件
./deploy.sh > deploy.log 2>&1
```

> 顺序很重要：`cmd 2>&1 > file` 和 `cmd > file 2>&1` 结果不同。牢记：**`> file 2>&1` 才对**。

## 管道

用 `|` 把前一个命令的输出，作为后一个命令的输入。组合成数据处理流水线：

```bash
# 找最大的 5 个文件
ls -lS /var/log | head -n 6

# 统计进程数
ps aux | wc -l

# 统计日志里某个词出现次数
grep "ERROR" app.log | wc -l

# 去重排序
cat a.txt | sort | uniq -c | sort -rn
```

> 管道是 Linux 命令行的灵魂。前端命令（ls/cat/grep/sort）输出到屏幕，后端命令（head/tail/wc/grep/awk）消费输入，层层加工（进阶见 [[7-Linux-文本处理三剑客]]）。

## 文本编辑器 vim

命令行环境最常用的编辑器是 vim，学习曲线陡但值得掌握。三种模式：

| 模式 | 进入 | 作用 |
|------|------|------|
| 普通模式 | 默认 | 移动、删除、复制 |
| 插入模式 | 按 `i` | 编辑文字 |
| 命令行模式 | 按 `:` | 保存、退出、查找 |

```bash
vim a.txt          # 打开文件
```

**新手最快上手序列**：

```
vim a.txt   → 按 i 进入插入模式 → 编辑内容
→ 按 Esc 回到普通模式 → 输入 :wq 回车（保存退出）
```

常用命令速查：

| 操作 | 按键 |
|------|------|
| 保存退出 | `:wq` |
| 不保存退出 | `:q!` |
| 保存 | `:w` |
| 删除当前行 | `dd` |
| 复制/粘贴行 | `yy` / `p` |
| 撤销 | `u` |
| 搜索 | `/word` |
| 跳转行号 | `:123` |

> 替代方案：新手可用 `nano`（界面友好），或装 IDE 的 vim 插件。但 SSH 到服务器上只能靠 vim/nano，建议至少掌握 `:wq` 和 `:q!`。

## 常见问题

**Q：`cat` 大文件刷屏卡死？**
A：用 `less` 分页查看。已经刷屏可 `Ctrl+C` 中断。

**Q：重定向后文件还是空的？**
A：可能错误输出没被捕获。加上 `2>&1`：`cmd > log 2>&1`。

**Q：vim 提示 `E37: No write since last change`？**
A：有未保存修改。保存 `:wq`，或强制放弃 `:q!`。

**Q：`tail -f` 怎么退出？**
A：按 `Ctrl+C`。
