# 10. 异常处理

## 本章目标

理解什么是异常，掌握 try/except/else/finally 的完整用法，学会自定义异常。

## 10.1 什么是异常

程序运行时发生的错误叫异常。不处理的话程序会**崩溃**：

```python
# 运行时报错
num = int("abc")     # ValueError: invalid literal for int()
```

```python
# 不处理异常：程序直接崩溃
nums = [1, 2, 3]
print(nums[5])       # IndexError: list index out of range
print("后面的代码不会执行")
```

**常见异常类型：**

| 异常 | 含义 | 触发场景 |
|------|------|----------|
| `ValueError` | 值错误 | 类型转换失败 |
| `TypeError` | 类型错误 | 不同类型运算 |
| `IndexError` | 索引越界 | 访问不存在的下标 |
| `KeyError` | 键不存在 | 字典取不存在的键 |
| `FileNotFoundError` | 文件不存在 | 打开不存在的文件 |
| `ZeroDivisionError` | 除以零 | `10 / 0` |
| `NameError` | 名字未定义 | 变量拼写错误 |

## 10.2 try / except：捕获异常

```python
try:
    num = int(input("请输入数字："))
    print(f"你输入的是：{num}")
except ValueError:
    print("输入的不是数字！")
# 输入 abc → 输入的不是数字！（程序不崩溃）
# 输入 42  → 你输入的是：42
```

**多个 except 处理不同类型：**

```python
try:
    nums = [1, 2, 3]
    index = int("a")        # 假设这里可能出错
    print(nums[index])
except ValueError:
    print("索引必须是数字")
except IndexError:
    print("索引超出范围")
```

## 10.3 捕获并获取异常信息

```python
try:
    result = 10 / 0
except ZeroDivisionError as e:
    print(f"出错了：{e}")    # 出错了：division by zero
```

**只捕获特定异常**，避免吞掉所有错误（不要用裸 `except:`）：

```python
# 不推荐：把所有错误都吞掉，问题难排查
try:
    ...
except:
    pass

# 推荐：明确捕获类型
try:
    ...
except (ValueError, TypeError):
    print("输入类型不对")
```

## 10.4 else 和 finally

```python
try:
    num = int(input("请输入数字："))
except ValueError:
    print("输入的不是数字")
else:
    # try 没出错时执行
    print(f"成功转换：{num}")
finally:
    # 无论如何都执行（适合关闭资源）
    print("程序结束")

# 输入 42 → 成功转换：42 / 程序结束
# 输入 abc → 输入的不是数字 / 程序结束
```

**finally 的典型用途：**

```python
f = None
try:
    f = open("data.txt", "r", encoding="utf-8")
    content = f.read()
except FileNotFoundError:
    print("文件不存在")
finally:
    if f:
        f.close()     # 无论如何都关闭文件
```

> 更推荐的做法：用 with 语句自动管理资源（见 [[9-Py-文件操作]]）。

## 10.5 主动抛出异常：raise

在程序里主动制造异常，用于检查前置条件：

```python
def set_age(age):
    if age < 0:
        raise ValueError("年龄不能为负数")
    print(f"年龄设为：{age}")

try:
    set_age(-5)
except ValueError as e:
    print(f"调用出错：{e}")
# 调用出错：年龄不能为负数
```

## 10.6 自定义异常

继承 `Exception` 创建自己的异常类：

```python
class BalanceError(Exception):
    """余额不足异常"""
    pass

class BankAccount:
    def __init__(self, balance=0):
        self.balance = balance

    def withdraw(self, amount):
        if amount > self.balance:
            raise BalanceError(f"余额不足！当前余额：{self.balance}，想取：{amount}")
        self.balance -= amount
        print(f"取款 {amount} 成功，剩余 {self.balance}")

# 使用
account = BankAccount(100)

try:
    account.withdraw(50)    # 取款 50 成功，剩余 50
    account.withdraw(200)   # 触发自定义异常
except BalanceError as e:
    print(f"银行系统提示：{e}")
```

**运行结果：**

```
取款 50 成功，剩余 50
银行系统提示：余额不足！当前余额：50，想取：200
```

**为什么自定义异常？** 让错误语义清晰，调用方可以精确区分"余额不足"和"其他错误"。

## 10.7 综合示例：健壮的输入函数

封装一个"永不崩溃"的数字输入：

```python
def get_number(prompt):
    """反复询问直到用户输入合法数字"""
    while True:
        try:
            value = float(input(prompt))
            return value
        except ValueError:
            print("输入无效，请输入数字！")

# 使用
num1 = get_number("请输入第一个数：")
num2 = get_number("请输入第二个数：")

try:
    print(f"{num1} / {num2} = {num1 / num2}")
except ZeroDivisionError:
    print("除数不能为 0")
```

**讲解：** `while True` + `try/except` + `return` 是处理用户输入的标准模式——输错就循环重问，直到合法。

## 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 裸 `except: pass` | 吞掉所有错误难排查 | 明确捕获异常类型 |
| 异常处理太宽泛 | `except Exception` 过多 | 尽量精确捕获 |
| 忘记 finally | 资源泄漏 | 用 with 或 finally |
| 在 except 里不处理直接 pass | 错误被忽略 | 至少打日志/提示 |
