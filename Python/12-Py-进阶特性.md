掌握装饰器、生成器、迭代器、上下文管理器和异步编程入门，这些是 Python 进阶的必备技能。

## 12.1 装饰器：给函数加"包装"

装饰器是**在不修改函数代码的前提下，给函数增加功能**的语法糖：

```python
import time

def timer(func):
    """计算函数运行时间的装饰器"""
    def wrapper(*args, **kwargs):
        start = time.time()
        result = func(*args, **kwargs)
        end = time.time()
        print(f"{func.__name__} 耗时 {end - start:.6f} 秒")
        return result
    return wrapper

# 使用装饰器：@ 语法糖
@timer
def slow_sum(n):
    total = 0
    for i in range(n):
        total += i
    return total

# 等价于 slow_sum = timer(slow_sum)
result = slow_sum(1000000)
print(f"结果：{result}")
```

**运行结果：**

```
slow_sum 耗时 0.028001 秒
结果：499999500000
```

**讲解：**
- `@timer` 把 `slow_sum` 函数传给 `timer`，返回包装后的 `wrapper`
- `wrapper` 先计时，再调用原函数，最后返回原结果
- `*args, **kwargs` 让装饰器适配任意参数的函数

### 带参数的装饰器

```python
def repeat(times):
    """重复执行 times 次的装饰器"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            for _ in range(times):
                func(*args, **kwargs)
        return wrapper
    return decorator

@repeat(3)
def say_hello():
    print("Hello!")

say_hello()
# Hello! / Hello! / Hello!
```

### 装饰器的实际应用

```python
# 登录检查装饰器
def require_login(func):
    def wrapper(user, *args, **kwargs):
        if not user.get("logged_in"):
            print("请先登录！")
            return
        return func(user, *args, **kwargs)
    return wrapper

@require_login
def view_profile(user):
    print(f"查看 {user['name']} 的个人资料")

view_profile({"name": "小明", "logged_in": False})   # 请先登录！
view_profile({"name": "小明", "logged_in": True})    # 查看 小明 的个人资料
```

## 12.2 生成器：按需生产数据

生成器**不会一次性把所有数据放进内存**，而是逐个产出（惰性求值）：

```python
def countdown(n):
    """生成器函数：包含 yield 的就是生成器"""
    while n > 0:
        yield n          # 产出当前值，暂停
        n -= 1           # 下次继续从这里执行

for i in countdown(3):
    print(i)             # 3 2 1
```

**对比内存占用（重点）：**

```python
# 一次性生成 1000 万个数据：占大量内存
big_list = [i for i in range(10_000_000)]

# 生成器：不占内存，用多少产多少
big_gen = (i for i in range(10_000_000))    # 生成器表达式

print(type(big_list))   # <class 'list'>
print(type(big_gen))    # <class 'generator'>

# 逐个取出
print(next(big_gen))    # 0
print(next(big_gen))    # 1
```

### 读取大文件的经典用法

```python
def read_large_file(file_path):
    """逐行读取大文件，不加载全部内容"""
    with open(file_path, "r", encoding="utf-8") as f:
        for line in f:
            yield line.strip()

# 使用（即使文件 10GB 也只会占一行内存）
for line in read_large_file("huge_log.txt"):
    if "ERROR" in line:
        print(line)
```

## 12.3 迭代器与可迭代对象

**可迭代对象**（能用 for 遍历）：列表、元组、字典、字符串、生成器等
**迭代器**（有 `__next__`）：用 `iter()` 转换

```python
nums = [1, 2, 3]

# 所有可迭代对象都能用 iter() 转成迭代器
it = iter(nums)

print(next(it))    # 1
print(next(it))    # 2
print(next(it))    # 3
# print(next(it))  # StopIteration（取完会报错）
```

**for 循环的本质**：for 就是反复调用 `next()` 直到 `StopIteration`：

```python
# for x in nums 等价于：
it = iter(nums)
while True:
    try:
        x = next(it)
        print(x)
    except StopIteration:
        break
```

## 12.4 上下文管理器：with 背后的原理

前面用过 `with open(...)`，自己也可以写上下文管理器：

```python
class Timer:
    """计时上下文管理器"""
    def __enter__(self):
        self.start = time.time()
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        self.elapsed = time.time() - self.start
        print(f"耗时 {self.elapsed:.4f} 秒")
        # 返回 False：异常继续传播；返回 True：吞掉异常

with Timer():
    total = sum(range(1_000_000))
    print(f"求和结果：{total}")
```

**运行结果：**

```
求和结果：499999500000
耗时 0.0364 秒
```

### contextlib 简化写法

```python
from contextlib import contextmanager

@contextmanager
def timer():
    start = time.time()
    try:
        yield          # yield 之前的代码是进入时执行，之后是退出时执行
    finally:
        elapsed = time.time() - start
        print(f"耗时 {elapsed:.4f} 秒")

with timer():
    time.sleep(0.5)
# 耗时 0.5000 秒
```

## 12.5 异步编程入门（asyncio）

异步让程序在等待 I/O 时做其他事（适合网络请求、文件读取）：

```python
import asyncio

async def fetch_data(name, delay):
    """模拟网络请求"""
    print(f"开始请求 {name}...")
    await asyncio.sleep(delay)      # await 让出控制权
    print(f"请求 {name} 完成")
    return f"{name} 的数据"

async def main():
    # 并发执行 3 个请求（总耗时约 2 秒而不是 1+2+3=6 秒）
    results = await asyncio.gather(
        fetch_data("A", 1),
        fetch_data("B", 2),
        fetch_data("C", 3),
    )
    print(results)

# 运行异步主函数
asyncio.run(main())
```

**运行结果：**

```
开始请求 A...
开始请求 B...
开始请求 C...
请求 A 完成
请求 B 完成
请求 C 完成
['A 的数据', 'B 的数据', 'C 的数据']
```

**讲解：**
- `async def` 定义协程（异步函数）
- `await` 遇到等待时让出控制权，程序去执行其他协程
- `asyncio.gather()` 并发执行多个协程

> 注意 `await asyncio.sleep()` 是模拟 I/O 等待。`time.sleep()` 是阻塞的，会卡住整个事件循环，异步代码里**不要用**。

## 12.6 综合示例：带重试的请求器

把本章知识组合起来：

```python
import time

def retry(max_attempts=3, delay=1):
    """重试装饰器：失败后等待再试"""
    def decorator(func):
        def wrapper(*args, **kwargs):
            for attempt in range(1, max_attempts + 1):
                try:
                    return func(*args, **kwargs)
                except Exception as e:
                    print(f"第 {attempt} 次失败：{e}")
                    if attempt == max_attempts:
                        raise
                    time.sleep(delay)
        return wrapper
    return decorator

@retry(max_attempts=3, delay=0.5)
def flaky_request():
    """模拟不稳定服务：前两次失败，第三次成功"""
    import random
    if random.random() < 0.7:
        raise ConnectionError("网络超时")
    return "请求成功"

try:
    result = flaky_request()
    print(f"最终结果：{result}")
except ConnectionError:
    print("全部重试失败")
```

## 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 装饰器忘返回 wrapper | 函数被替换成 None | `return wrapper` |
| 生成器只 next 一次 | 生成器不可重用 | 重新创建 |
| 异步代码里用 time.sleep | 阻塞事件循环 | 用 `await asyncio.sleep()` |
| `asyncio.run()` 重复调用 | 事件循环已关闭 | 每个入口只调用一次 |
