# 11. 面向对象编程

## 本章目标

理解类与对象、`self`、`__init__` 构造方法，掌握继承、方法重写和常用魔术方法。

## 11.1 类与对象

**类（Class）** 是模板，**对象（Object）** 是根据模板创建的实例：

```python
# 定义类
class Dog:
    def __init__(self, name, age):
        self.name = name    # 属性：实例变量
        self.age = age

    def bark(self):         # 方法：定义在类里的函数
        print(f"{self.name} 汪汪叫！")

# 创建对象（实例化）
dog1 = Dog("旺财", 3)
dog2 = Dog("小白", 5)

# 访问属性、调用方法
print(dog1.name)        # 旺财
print(dog2.age)         # 5
dog1.bark()             # 旺财 汪汪叫！
dog2.bark()             # 小白 汪汪叫！
```

**关键概念：**
- `__init__` 是构造方法：创建对象时自动调用，用于初始化属性
- `self` 指当前实例：`self.name = name` 把参数存进对象
- 同一个类创建的对象**各自独立**（改 dog1 不影响 dog2）

## 11.2 属性与方法

```python
class Student:
    # 类属性：所有实例共享
    school = "第一中学"

    def __init__(self, name, score):
        # 实例属性：每个实例独立
        self.name = name
        self.score = score

    def get_grade(self):
        if self.score >= 90:
            return "优秀"
        elif self.score >= 60:
            return "及格"
        else:
            return "不及格"

    def info(self):
        print(f"{self.name}（{self.school}）成绩 {self.score} 分，评级：{self.get_grade()}")

# 使用
s1 = Student("小明", 92)
s2 = Student("小红", 58)

print(Student.school)      # 第一中学  通过类访问
print(s1.school)           # 第一中学  通过实例访问
s1.info()                  # 小明（第一中学）成绩 92 分，评级：优秀
s2.info()                  # 小红（第一中学）成绩 58 分，评级：不及格
```

> 实例属性优先于类属性。改 `Student.school` 影响所有实例。

## 11.3 继承

子类继承父类的方法和属性，可复用父类代码：

```python
# 父类（基类）
class Animal:
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(f"{self.name} 在吃东西")

    def speak(self):
        print("动物发出声音")

# 子类（派生类）
class Dog(Animal):
    def speak(self):          # 重写父类方法
        print(f"{self.name} 汪汪叫")

class Cat(Animal):
    def speak(self):
        print(f"{self.name} 喵喵叫")

# 使用
d = Dog("旺财")
c = Cat("咪咪")

d.eat()        # 旺财 在吃东西    （继承自 Animal）
d.speak()      # 旺财 汪汪叫      （Dog 自己的实现）
c.speak()      # 咪咪 喵喵叫      （Cat 自己的实现）
```

**继承的好处**：公共逻辑（如 `eat`）写在父类一次，子类专注自己的差异（重写 `speak`）。

### super() 调用父类方法

```python
class Animal:
    def __init__(self, name):
        self.name = name
        print(f"Animal 初始化：{name}")

class Dog(Animal):
    def __init__(self, name, breed):
        super().__init__(name)      # 调用父类的 __init__
        self.breed = breed

    def info(self):
        print(f"{self.name} 是 {self.breed}")

d = Dog("旺财", "金毛")
d.info()
# Animal 初始化：旺财
# 旺财 是 金毛
```

### isinstance 类型检查

```python
d = Dog("旺财", "金毛")
print(isinstance(d, Dog))       # True
print(isinstance(d, Animal))    # True  子类实例也是父类类型
```

## 11.4 魔术方法（dunder methods）

以双下划线开头的方法，让对象支持特殊语法：

```python
class Point:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    # str()：print 对象时调用
    def __str__(self):
        return f"Point({self.x}, {self.y})"

    # repr()：交互式环境显示
    def __repr__(self):
        return f"Point({self.x}, {self.y})"

    # + 运算符
    def __add__(self, other):
        return Point(self.x + other.x, self.y + other.y)

    # == 比较
    def __eq__(self, other):
        return self.x == other.x and self.y == other.y

    # len()
    def __len__(self):
        return 2

p1 = Point(1, 2)
p2 = Point(3, 4)

print(p1)                  # Point(1, 2)     __str__
print(p1 + p2)             # Point(4, 6)     __add__
print(p1 == Point(1, 2))   # True            __eq__
print(len(p1))             # 2               __len__
```

**常用魔术方法速查：**

| 方法 | 触发场景 |
|------|----------|
| `__init__(self)` | 创建对象时 |
| `__str__(self)` | `print(obj)` / `str(obj)` |
| `__repr__(self)` | 交互式显示 |
| `__len__(self)` | `len(obj)` |
| `__add__/__sub__/__mul__` | `+ - *` 运算 |
| `__eq__/__lt__/__gt__` | 比较运算 |
| `__getitem__(self, key)` | `obj[key]` 索引 |

## 11.5 属性和方法的可见性

Python 用命名约定表示"私有"（不是强制，是习惯）：

```python
class Account:
    def __init__(self, balance):
        self.__balance = balance    # 双下划线：约定私有（改名保护）

    def deposit(self, amount):
        if amount <= 0:
            print("金额必须为正")
            return
        self.__balance += amount
        print(f"存入 {amount}，余额 {self.__balance}")

    def get_balance(self):
        return self.__balance

acc = Account(100)
acc.deposit(50)              # 存入 50，余额 150
print(acc.get_balance())     # 150
# print(acc.__balance)       # AttributeError（被改名保护）
```

**命名约定：**
- `name` — 公开
- `_name` — 单下划线：内部使用约定
- `__name` — 双下划线：类内使用（改名保护）

## 11.6 @property：属性访问控制

用方法模拟属性，读写时执行逻辑：

```python
class Temperature:
    def __init__(self, celsius):
        self._celsius = celsius

    @property
    def celsius(self):
        return self._celsius

    @property
    def fahrenheit(self):
        return self._celsius * 9 / 5 + 32

    @celsius.setter
    def celsius(self, value):
        if value < -273.15:
            raise ValueError("温度不能低于绝对零度")
        self._celsius = value

t = Temperature(25)
print(t.celsius)          # 25        像属性一样访问
print(t.fahrenheit)       # 77.0      自动计算

t.celsius = 30            # setter 生效
print(t.fahrenheit)       # 86.0

# t.celsius = -300        # ValueError：温度不能低于绝对零度
```

**好处**：外部用起来像普通属性，内部可以加校验逻辑。

## 11.7 综合示例：银行账户系统

```python
class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.__balance = balance
        self.__transactions = []

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("存款金额必须为正")
        self.__balance += amount
        self.__transactions.append(f"存款 +{amount}")

    def withdraw(self, amount):
        if amount <= 0:
            raise ValueError("取款金额必须为正")
        if amount > self.__balance:
            raise ValueError("余额不足")
        self.__balance -= amount
        self.__transactions.append(f"取款 -{amount}")

    def get_balance(self):
        return self.__balance

    def show_history(self):
        print(f"账户 {self.owner} 的交易记录：")
        for t in self.__transactions:
            print(f"  {t}")
        print(f"当前余额：{self.__balance}")

# 使用
acc = BankAccount("小明", 1000)
acc.deposit(500)
acc.withdraw(200)
acc.show_history()
```

**运行结果：**

```
账户 小明的交易记录：
  存款 +500
  取款 -200
当前余额：1300
```

## 常见错误

| 错误 | 原因 | 解决 |
|------|------|------|
| 忘记 `self` 参数 | 方法定义缺 self | 所有实例方法第一个参数是 self |
| `__init__` 拼错 | 少下划线/写错 | 检查双下划线 |
| 直接访问 `__xxx` 报错 | 私有属性改名保护 | 提供 getter/setter |
| 继承时忘记 `super().__init__` | 父类属性未初始化 | 子类 `__init__` 里调用 |
